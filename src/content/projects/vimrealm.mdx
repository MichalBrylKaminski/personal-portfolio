## What it is

Vimrealm is an isometric, pixel-art fantasy RPG that teaches Vim motions from scratch. It is for developers who are comfortable writing code but have never learned Vim, and it teaches Vim the way Vim is used: by typing real Vim commands. There are no multiple-choice quizzes and no flashcards.
